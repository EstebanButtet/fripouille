# Assistant IA personnel

Assistant IA local, modulaire et sécurisé.

## Environnement

- Windows 10
- Python 3.14
- Environnement virtuel Python : `.venv`

## Installation locale

Le paquet est installé en mode modifiable depuis le dossier `src`.

Pour activer l’environnement virtuel :

```powershell
cd "$HOME\Dev\assistant-ia"
.\.venv\Scripts\Activate.ps1
